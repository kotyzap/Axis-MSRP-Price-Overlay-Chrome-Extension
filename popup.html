Prices are Axis MSRP (list price), not street price. EUR is from the AXIS Price List, July 2026 (camera products only - EUR isn't available for non-camera categories like 2N, recorders, or accessories). USD for those same products is calculated from the EUR price at the EUR/USD rate in effect when this list was last generated (1 EUR ≈ 1.1387 USD, per xe.com on 2026-07-14) - it is not an independently published Axis USD price list, so treat it as an estimate. JPY is converted live from the EUR price using the current EUR/JPY reference rate (ECB, via api.frankfurter.dev), refreshed on the same weekly schedule as chipset data. Chipset info is sourced from CamStreamer's published app-compatibility list, not Axis. None of this refreshes automatically except chipset data and FX rates via the weekly background check or the Update button above. 価格はAxisのMSRP(希望小売価格)であり、実売価格ではありません。EUR価格は2026年7月版のAXIS Price Listに基づいています(カメラ製品のみが対象で、2Nやレコーダー、アクセサリーなどカメラ以外のカテゴリーにはEUR価格がありません)。同製品のUSD価格は、このリストが最後に生成された時点のEUR/USDレート(1 EUR ≈ 1.1387 USD、2026-07-14時点のxe.com調べ)でEUR価格から換算した参考値であり、Axisが独自に発表しているUSD価格表ではないため、あくまで目安としてください。JPY価格は、現在のEUR/JPY参照レート(ECB、api.frankfurter.dev経由)を使ってEUR価格からリアルタイムに換算しており、チップセット情報と同じ週次スケジュールで更新されます。チップセット情報はAxisではなくCamStreamerが公開しているアプリ対応リストが出典です。これらはチップセットデータとFXレートが週次のバックグラウンドチェックまたは上のUpdateボタンで更新される以外、自動的には更新されません。
